# 🎮 PS5 GTA VI Live Countdown & Pre-load Stream Overlay (Ready to Run)

This folder contains **all standalone main files** for the PlayStation 5 GTA VI countdown overlay. Everything is self-contained in this single folder with zero external dependencies.

## 🚀 How to Run

### 1. In OBS Studio
1. Open **OBS Studio**.
2. Add a new **Browser** source to your scene.
3. Check **Local file**.
4. Browse and select `index.html` inside this folder.
5. Set Width: `1920`, Height: `1080` (or your stream resolution).
6. Check **Control audio via OBS** and **Refresh browser when scene becomes active**.

### 2. In Any Web Browser
* Simply double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
* Press `F11` for complete edge-to-edge full-screen display.

## ⌨️ Hotkeys & Stream Controls

| Key | Action |
| :--- | :--- |
| **`E`** or **Click Card** | Toggle between **Ultimate Edition** (`₹7,499`) and **Standard Edition** (`₹5,999`). |
| **`M`** | Toggle PS5 background music on / off. |
| **`O`** | Toggle **OBS Broadcast Mode** (hides configuration buttons and cursors). |
| **`1`**, **`2`**, **`3`** | Switch between 4K official Rockstar wallpapers in real time. |
| **`Esc`** or **Double-Click** | Open the **Settings Drawer** to customize launch date, pre-load hours, etc. |
